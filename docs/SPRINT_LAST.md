# Финальный спринт (итерация качества и интеграции)

## Функциональность и API

| Задача | Результат |
|--------|-----------|
| **Только для авторизованных** | Нижняя навигация скрыта до успешного входа; переходы к экранам и поиск без входа блокируются. |
| **Избранное** | Карточка: кнопка «Открыть рецепт»; в окне рецепта — «Добавить недостающие в список покупок» (по кладовой и API при `meal_id`). |
| **TheMealDB как единый клиент** | Модуль `code/mealdb_api.py`: поиск по основному ингредиенту (`filter.php`), резервный поиск по названию (`search.php`), загрузка полного рецепта по `id` (`lookup.php`). |
| **Избранное и БД** | В таблицу `favorites` добавлено поле `meal_id` (миграция при старте). Сохраняются ингредиенты и инструкция; для рецептов из API — дедупликация по `meal_id`, для своих — по названию. |
| **Добавление в избранное из карточки** | Перед сохранением при необходимости подгружается полный рецепт с API, чтобы в избранном были полные данные. |
| **«Недостающие в покупки»** | Для результатов поиска без `full_ingredients` ингредиенты подгружаются через `lookup_meal` и сравниваются с кладовой. |
| **Подсветка ингредиентов** | В деталях рецепта ингредиенты подсвечиваются зелёным (есть в кладовой) или красным (нет). |
| **Добавление недостающих в кладовую** | Кнопка «Добавить недостающие в кладовую» добавляет отсутствующие ингредиенты с количеством 0 напрямую в pantry. |
| **Расширенные клавиатурные shortcuts** | Enter для подтверждения действий, Escape для очистки полей во всех экранах с вводом. |
